# Smart ATM Interface

## CodSoft Java Development Internship - Task 3

A console-based ATM application developed using Java and
Object-Oriented Programming concepts.

## Features

- PIN Authentication
- Check Account Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Daily Withdrawal Limit
- Insufficient Balance Validation
- Input Validation
- Transaction Date & Time

## Technologies Used

- Java
- OOP
- ArrayList
- Java Date & Time API
- Exception/Validation Handling

## Project Structure

- ATMInterface.java - Main ATM application
- BankAccount.java - Account and transaction operations
- Transaction.java - Transaction record management

## How to Run

Compile:

javac ATMInterface.java BankAccount.java Transaction.java

Run:
